# Submission-Readiness Checklist

## Scientific core
- [x] Final benchmark has a genuine nested 8→4→2→1 hierarchy.
- [x] Central hypothesis is falsifiable and independent of a method win.
- [x] Theory states sufficient conditions, not an overclaimed universal law.
- [x] Direct causal experiment rerun on 100 untouched seeds.
- [x] Broad heterogeneous benchmark retained as a null/negative result.
- [x] Empirical phase diagram spans transfer × prevalence × budget × noise.
- [x] Entanglement, horizon, and stochasticity stress tests included.
- [x] Alternative support metrics included.
- [x] Multiple representation/update regimes included.
- [x] Negative results are reported.

## Statistics
- [x] Paired bootstrap confidence intervals.
- [x] Paired parametric tests.
- [x] Nonparametric robustness checks where applicable.
- [x] Holm correction for multi-method main comparisons.
- [x] Effect sizes reported in addition to p-values.
- [x] Power analysis used to avoid overinterpreting sub-pp main effects.

## Reproducibility
- [x] No GPU required.
- [x] No API/network/model weights required.
- [x] Raw CSVs included.
- [x] Figure-generation scripts included.
- [x] Auto-generated numeric results file included.
- [x] Portable relative paths in final H8 scripts.
- [x] Clean-copy smoke test passed.
- [x] `run_all.sh` included.

## Manuscript
- [x] Blinded manuscript.
- [x] Related work updated through August 2026.
- [x] Proof appendix.
- [x] Full experiment appendix.
- [x] Reproducibility appendix.
- [x] Limitations and broader impact.
- [x] Reviewer simulation.

## Remaining external-validity risk
- [ ] Real LLM/tool-use validation. This is intentionally outside the executable-only scope and remains the main reviewer weakness.
